# 相信厚积薄发和功利性

今天看了一个视频是有关是否相信厚积薄发的，还看了一篇文章是关于工作的边界和感兴趣的边界的，我感觉这里有一些东西可以作为一个思考的方向，故做一个记录。

我们在工作之外总会有一些感兴趣的东西，当我们懂一些的时候，我们可以知道自己懂还是不懂，当我们完全不懂的时候就完全不知道自己懂还是不懂，这就是道德经所谓的“病”，我们通过不知道来做决策就是病病，我最近在做的一个项目因为很多东西都是从头设计，所以我经常会遇到不知道这样是不是正确的境地，在这种情况下我只能通过我不知道的地方做假设，假设之后逻辑链能闭合那我就可以继续往下做，甚至有些地方我明知道这样是不符合实际的，但是我可以先假设，然后后期把这里改造成我需要的杨子，否则我就根本没办法往下做。这就是病病，根据现有的条件和不知道的东西保证自己的逻辑链。

说远了，回过来说知识的问题，忘记是不是苏格拉底说的了，一个人的知识就像一个圆，越是渊博的知识就让人感受到自己的无知，当我工作两三年的时候我感觉自己还差一点就能了解全部的前端问题，当我工作五年的时候我感觉自己仿佛离计算机的本质很近了，现在我工作七年左右了，我发现自己别说计算机的本质，我感觉连本职工作中的前端都有太多的东西需要去学习了。

每当这个时候我就会陷入迷茫，我是应该抱着现有的知识去解决问题呢，还是继续的去深入学习呢，我学习的那些东西真的有用吗，就像我看了《程序员的自我修养》，我了解了一个hello world是如何经历计算机的编译、装载和系统库最终显示一个短短的输出，但是我还是因为一个小小的bug在那里调试了一个小时，最终改动了一行代码发现解决了，就像我看了《人月神话》，我了解了最高效的团队方式，我了解了最合理的人员搭配，可我还是只能按照公司的安排去做一个螺丝钉。每当这个时候我就会产生一种我看的那些书，我学的那些好像屠龙之技的东西，到底有没有用。

然后我今天看到一个视频，他说我要不要相信厚积薄发，一个人是不是牛马在出生的时候就已经决定了，在如何努力也只是一个大一点的牛马，所谓的质变是根本不会发生的，然后这个人说，这其实是一个相信的问题，你相信量变引起质变，你相信厚积薄发，这也是一种能力，如果你相信，那么你就会怀着一个积极的心态去面对这个世界，如果你不相信，那么人就会变得消极，相信也是一种难能可贵的能力，马克思主义写的明明白白，量变引起质变，你要相信你的努力会有质变的一天，这样才能满怀信心的迎接这个世界的未来。

正如我之前和女朋友产生过一次争论，我这个人爱好光，名著，佛经都有看过一些，可是我女朋友却有点不屑，说我看这些还不如看看如何成功，社交礼仪的书，可我却不喜欢那样的书，我觉着那些小说不光让我知道中国的礼仪，还可以让我知道国外的礼仪，我可以在不同的国别直接自由的翱翔，我也可以在佛经和道德经找到属于自己的宁静，我也可以在哲学和历史中寻求世界的真相，可能我这些都无法让我获得现成的好处，可以做任何事情都想着获得点什么是不是太功利了一点，这个世界有时候很难，每个人可能都需要一种让自己可以暂时不理现实世界的纷纷扰扰去寻找属于自己的那份平静。这些东西可能并没有那么多的收获，可是一个人的经历，一个人读过的书，即使遗忘了，也会变成血肉融入到一个人的骨子里。

写到这里这片文章就要结束了，我也不知道厚积薄发，功利性和我上面说的那些东西有没有必然的联系，可在我心里这些是有很强的关联的，所以在最后我用王阳明的一句话来作为结尾吧——“心外无物，心外无理”
