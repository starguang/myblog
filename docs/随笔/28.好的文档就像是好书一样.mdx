# 好的文档就像是好书一样

如何评价一本书是一个好书呢，我想其中很重要的一点就是你在人生的不同阶段，在对事物的理解不同的时候，读起来都是有收获的，所谓常读常新。我想好的文档也应该是这样的—在面对不同水平的读者都能让读者有所收获。

在这里我需要夸奖一下react的新文档：[react文档](https://react.dev)

我在刚学习react的时候还是旧版的react，那时候还是react15，旧版的react文档对于初学者来说就比较难懂，在我用react有一年的时间之后我又去👀react的旧版文章，在里面读出了很多不一样的内容，让我对react的理解更加深刻了一些。但是新版的react文档则完全不一样，如果是入门者，很容易学到react的入门知识和学到react的理念已经开发中需要注意的问题，让入门者可以很容易上手。然而作为一个用了react挺多年的人来说，在新版文档发布之后我也仔细的通读了一遍，把其中的练习也做了一遍，在通读的过程中我也更加深入的理解了react的设计模式以及react的理念，或者说的更加有逼格一些，就叫react的哲学。总结起来就是以下三点：

1. 单项数据流
2. 不可变性
3. 以及数据驱动视图

其中还有一个让我印象深刻的文章叫做《你可能不需要effect》正是这篇文章让我在每次用effect的时候都有思索再三：我真的需要这个effect吗？也让我努力的去先设计，再编码，当设计的足够强大的时候，代码就会很自然的写出来，所谓合道，不外如是。
