# 奥运观赛

其实我是不咋关注奥运的，因为我感兴趣的更多的是篮球，不过说实话，奥运会的篮球真不一定有NBA好看，所以我很少看。不过对象对奥运挺感兴趣的，尤其是乒乓球，所以周末就一块看了几场比赛，不过看完乒乓之后我会看会儿篮球的比赛，主要还是看美国队的比赛。

然后我对象跟我一块看的时候就有了一系列的对话：

她：你说投篮可不可以在篮框边上给他拍出去。

我：？？？你咋上来就想着钻空子，当然是不可以了，防守队员只能在篮球的上升途中拦截，下降途中属于干扰球，是犯规的。

她：为什么篮框下那个有颜色的地方都没有进攻的队员，他们不在那里抢篮板吗。

我：那里是三秒区，进攻队员在那里超过三秒就犯规了，NBA还有防守三秒，没有防守带球的人在那里超过三秒也属于犯规。

她：那个人都到篮下离篮框那么近了怎么还要传出去，投啊。

我：你怕是不知道那帮人的身高臂展，那里全是人，你投篮百分之百会被盖帽的。
